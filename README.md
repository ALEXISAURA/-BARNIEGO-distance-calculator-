# Distance calculator


## Description
Our program is all about calculating a distance between two points using the distance formula, distance is equals to x sub 2 minus x sub 1 raised to the power of 2 plus y sub 2 minus y sub 1 raised to the power of 2 to square root of 2. I already grouped the two pints so that the code can run smoothly. It tells us how far the two points are depending on the value. We also used sqrt and pow to represent the square root and the power of 2 in both the x and y values. It allows you to input values and prints the final value all by itself thanks to the equation we set up.


## How to run

1. Open the program.
2. Run the program.
3. Enter the required values.
